단계수립

필요한것을 나에게 요청하라




1. 과제 추진 배경
현재 견적서를 검토할 때는 보통 과거 유사 발주 데이터를 사람이 직접 찾아보고 비교하는 방식이 많습니다.
그런데 이 방식은 다음과 같은 문제가 있습니다.

유사 품목 매칭이 수작업이라 시간이 오래 걸림
같은 견적 대상이라도 참조하는 이력에 따라 단가가 다르게 추출될 수 있음
검토자의 경험에 따라 판단 편차가 발생할 수 있음
외부 시세나 할인 조건을 체계적으로 반영하기 어려움
이 과제는 이런 문제를 해결하기 위해,
기존 견적/발주 데이터를 학습한 AI와 룰 기반 분석을 결합하여 견적 적정성을 자동 검토하는 것을 목표로 합니다.

2. 과제의 핵심 목표
이 과제의 핵심은 크게 4가지입니다.

표준단가 DB 구축
협력사 견적서 자동 분석
견적가 검토 및 최적 가격 제안
표준단가 지속 업데이트
즉, 한 번 분석하고 끝나는 것이 아니라,
견적 검토 결과가 다시 데이터로 축적되어 표준단가가 계속 고도화되는 선순환 구조를 만드는 것이 중요합니다.

3. 전체 프로세스 설명
3-1. 표준단가 DB 구축
첫 번째 단계는 표준단가 데이터베이스(DB) 를 만드는 것입니다.

주요 내용
기존 견적 데이터, 발주 데이터, 계약 단가 이력 등을 수집
견적서 양식을 표준화
품목을 유형별로 정리
물품
설비
공사
용역
왜 필요한가
견적서를 자동으로 비교하려면 먼저 기준이 되는 표준 가격 체계가 있어야 합니다.
따라서 과거 데이터를 정리해 “이 품목은 보통 얼마 수준이 적정한가” 를 보여주는 기준 DB를 구축해야 합니다.

기대 효과
검토 기준의 일관성 확보
담당자별 편차 감소
향후 AI 분석 정확도 향상
3-2. 협력사 견적서 자동 분석
두 번째 단계는 협력사가 제출한 견적서를 시스템이 자동으로 읽고 분석하는 것입니다.

주요 기능
표준단가 검색
동일품 또는 유사품의 과거 표준단가 조회
할인율 적용
사전에 정의한 룰에 따라 할인 조건 자동 반영
외부 시장가 검색
표준단가 DB에 없는 경우 외부 시세 정보 조회
RPA 또는 Open API 기반으로 시장가격 수집 가능
의미
이 단계에서는 단순히 문서를 읽는 것을 넘어서,
해당 견적 품목이 과거 어떤 품목과 유사한지,
기존 단가 수준은 어떤지,
추가로 할인이나 시장 시세까지 반영하면 적정 가격이 어느 정도인지를 자동으로 판단하는 기반을 마련합니다.

3-3. 견적가 검토 및 최적화
세 번째 단계는 실제로 이 견적 가격을 채택할지, 조정할지 판단하는 단계입니다.

경우 1. 표준단가 DB에 있는 품목
이 경우에는 기준 데이터가 있으므로 다음과 같이 검토할 수 있습니다.

표준단가와 비교
차이율 분석
허용 범위 초과 여부 확인
필요 시 표준단가 적용 또는 견적가 적용 결정
즉, 협력사가 제시한 가격이 합리적이면 견적가를 인정하고,
과도하게 높다면 표준단가 기준으로 조정할 수 있습니다.

경우 2. 표준단가 DB에 없는 품목
이 경우에는 내부 기준이 부족하므로 아래와 같이 판단합니다.

사전 정의 할인율 적용
외부 시장가격 비교
유사 품목 추론
필요 시 시장가 기준 또는 할인 적용 가격 제시
즉, 데이터가 없는 신규 품목이라도 시장가 + 할인 룰 + 유사 품목 분석을 통해 합리적인 검토가 가능하도록 합니다.

핵심 산출물
적정 단가 제안
검토 의견 자동 생성
협상 참고 가격 제시
예외 항목 식별
3-4. 표준단가 업데이트
마지막 단계는 검토한 결과를 다시 DB에 반영하는 것입니다.

주요 내용
실제 검토된 견적 데이터 축적
승인 단가/계약 단가 이력 반영
지속적인 비교/분석 수행
표준단가 추천 로직 업데이트
왜 중요한가
AI 시스템은 처음부터 완벽하지 않습니다.
하지만 검토 데이터가 계속 쌓이면,
어떤 품목은 어느 범위가 적정한지 더 정확하게 학습하게 됩니다.

즉, 시간이 갈수록

표준단가 DB가 풍부해지고
자동 추천 정확도가 높아지고
검토 속도가 빨라지고
구매 경쟁력이 강화됩니다
4. 이 과제를 한 문장으로 정리하면
“과거 견적·발주 이력, 할인 룰, 외부 시장가를 결합해 협력사 견적의 적정성을 AI로 자동 분석하고, 그 결과를 다시 표준단가 DB에 축적해 지속적으로 고도화하는 시스템 구축 과제”입니다.

5. 업무 관점에서의 기대 효과
원자재 구매/구매기획 업무 관점에서 보면 다음 효과를 기대할 수 있습니다.

정량 효과
견적 검토 시간 단축
수작업 비교 분석 감소
과다 견적 사전 차단
표준단가 활용률 증가
정성 효과
담당자 경험 의존도 감소
검토 기준 표준화
협력사 대응 논리 강화
가격 협상력 향상
구매 의사결정의 객관성 확보
