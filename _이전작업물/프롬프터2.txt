# 1페이지 설명: 표준/시장 단가 DB 조회 및 협력사 견적서 등록

## 1. 표준/시장 단가 DB 조회

왼쪽 화면은 **표준 DB 현황 조회**와 **시장가 DB 현황 조회** 기능을 설명합니다.

### 주요 기능
- **표준 단가 DB 조회**
  - 사내에 축적된 과거 견적, 발주, 계약 이력 기반의 기준 단가 확인
- **시장가 DB 조회**
  - 외부 시장가격, 시세 정보 등을 반영한 단가 데이터 확인
- **단가 반영 이력 조회**
  - 특정 품목의 단가가 언제, 어떤 기준으로 반영되었는지 이력 확인
- **이전 단가 반영 가능**
  - 필요 시 과거 기준 단가를 참고하거나 재적용 가능

### 의미
이 기능은 단순 조회가 아니라, 견적 검토 시 **비교 기준을 명확히 확보하는 역할**을 합니다.  
즉, 담당자는 견적가를 검토할 때 현재 기준 단가뿐 아니라 과거 반영 이력까지 확인하면서,  
왜 이 단가가 형성되었는지 근거를 추적할 수 있습니다.

### 업무적 효과
- 기준 단가에 대한 **투명성 확보**
- 단가 변경 이력 관리 가능
- 협력사 견적 검토 시 **객관적 비교 근거** 제공
- 가격 협의 시 설명 자료로 활용 가능

## 2. 협력사 견적서 등록

오른쪽 화면은 **협력사 견적서 등록 기능**을 보여줍니다.

### 주요 기능
- **엑셀 파일 형식의 견적서 업로드**
  - 협력사가 제출한 견적서를 시스템에 바로 등록 가능
- **업로드 내역 확인**
  - 어떤 파일이 올라왔는지 확인 가능
- **상세 내용 점검**
  - 업로드된 견적 품목, 수량, 금액, 규격 등 세부 정보 검토 가능

### 의미
실제 현업에서는 협력사 견적서가 대부분 엑셀 형태로 오기 때문에,  
이 기능은 견적서를 수기로 다시 입력하지 않고 **파일 업로드 기반으로 빠르게 등록**하도록 지원합니다.

또한 등록 후 바로 상세 내용을 확인할 수 있기 때문에,
- 파일 누락 여부
- 품목 정보 오류
- 단가/수량 이상 여부

등을 초기에 점검할 수 있습니다.

### 업무적 효과
- 견적 접수 및 등록 시간 단축
- 수기 입력 오류 감소
- 견적서 관리의 일관성 확보
- 이후 자동 분석 단계로 자연스럽게 연계 가능
