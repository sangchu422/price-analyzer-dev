# 실행 우선순위 로드맵
# 협력사 견적 단가 AI 비교·분석 시스템

---

## 우선순위 요약 (한눈에 보기)

```
P0 (즉시 착수)          P1 (MVP 이후)           P2 (고도화)
──────────────────      ──────────────────      ──────────────────
① 데이터 수집·정제      ④ 리포트 출력           ⑦ 단가 추이 그래프
② AI 유사도 엔진 PoC    ⑤ 단가 시뮬레이터        ⑧ 시장가 자동 수집
③ MVP 앱 개발           ⑥ DB 자동 갱신 워크플로
```

---

## Phase 0: 선행 준비 (과제 착수 전, 1~2주)

### ① 데이터 수집 및 정제 ★★★ (가장 중요)

**왜 먼저 해야 하는가?**
AI 모델과 표준단가 DB는 데이터가 없으면 동작하지 않음. 모든 것의 기반.

**구체적 액션**

| 액션 | 내용 |
|------|------|
| 1-1 | 최근 2~3년 구매 확정 견적 데이터 취합 (ERP 또는 담당자 파일) |
| 1-2 | 품목명 / 규격 / 단가 / 구매일 / 공급사 컬럼 기준으로 정제 |
| 1-3 | 중복 제거, 이상값 필터링 |
| 1-4 | 표준 품목코드·품목명 체계 정의 (분류 체계 설계) |
| 1-5 | 표준단가 DB 초기 적재 (최소 500건 이상 목표) |

**산출물**: 정제된 표준단가 DB 초기 데이터셋 (Excel → DB)

---

## Phase 1: MVP 개발 (2~6주)

### ② AI 유사도 엔진 PoC ★★★

**구체적 액션**

| 액션 | 내용 |
|------|------|
| 2-1 | 품목명 임베딩 모델 선정 (한국어 지원: KoBERT, ko-sroberta 등) |
| 2-2 | 표준단가 DB 품목명을 벡터화하여 인덱스 구축 |
| 2-3 | 입력 품목명 → 유사도 상위 5개 품목 반환 테스트 |
| 2-4 | 정확도 검증 (샘플 100건 수동 평가) → 임계값 조정 |

**판단 기준**: 유사도 정확도 80% 이상 시 다음 단계 진행

### ③ MVP 애플리케이션 개발 ★★★

**구체적 액션**

| 액션 | 내용 |
|------|------|
| 3-1 | **견적서 파싱**: Excel 업로드 → 품목·단가 자동 추출 |
| 3-2 | **유사도 검색 UI**: 추출 품목별 표준단가 매핑 결과 화면 |
| 3-3 | **비교표 UI**: 견적가 / 표준단가 / 차이율 테이블, 이상가 하이라이트 |
| 3-4 | MVP 내부 테스트 (실제 견적서 5건 이상으로 검증) |

**권장 기술 스택**

| 구분 | 도구 |
|------|------|
| 파싱 | Python (openpyxl, pdfplumber) |
| AI 엔진 | sentence-transformers + FAISS |
| 백엔드 | FastAPI |
| 프론트 | Streamlit (빠른 개발) 또는 React |
| DB | PostgreSQL + pgvector |
