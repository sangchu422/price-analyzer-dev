## 2. 제품 비전

> "담당자가 견적서를 업로드하면 30초 안에 표준단가·시장가와의 비교 결과와 협상 근거를 자동으로 받아보는 구매 지원 도구"

---

## 3. 사용자 페르소나

### Persona A — 메인 사용자: 구매 책임매니저
- **목표**: 빠른 견적 검토, 협상 근거 확보
- **Pain**: 견적서마다 품목 표기가 달라 수작업 매핑에 시간 낭비
- **기대**: AI가 유사 품목을 찾아주고, 적정가 범위를 바로 보여주길 원함

### Persona B — 보조 사용자: 구매 사원
- **목표**: 견적 데이터 입력·정리
- **Pain**: 표준단가 기준이 없어 검토 요청 전 사전 정리 불가
- **기대**: 입력 화면이 단순하고 가이드가 명확하길 원함

## 4. 핵심 사용자 스토리 (User Stories)

| ID | 사용자 | 스토리 | 우선순위 |
|----|--------|--------|----------|
| US-01 | 책임매니저 | 견적서(Excel/PDF)를 업로드하면 품목·수량·단가가 자동 추출된다 | P0 |
| US-02 | 책임매니저 | 추출된 품목에 대해 표준단가 DB에서 유사 품목을 AI로 검색하여 단가 범위를 확인한다 | P0 |
| US-03 | 책임매니저 | 견적가 vs 표준단가 vs 시장가를 한 화면에서 비교하고 이상가를 하이라이트로 확인한다 | P0 |
| US-04 | 책임매니저 | 비교 결과를 Excel 리포트로 내려받아 협상 자료로 활용한다 | P1 |
| US-05 | 책임매니저 | 할인율·물가 조정률을 직접 입력하여 조정 단가를 시뮬레이션한다 | P1 |
| US-06 | 구매 사원 | 확정된 구매 단가를 시스템에 등록하면 표준단가 DB에 자동 반영된다 | P1 |
| US-07 | 책임매니저 | 품목별 단가 이력(월별 추이)을 그래프로 조회한다 | P2 |
| US-08 | 책임매니저 | 외부 시장가(나라장터, 유통가 등)를 수동 입력하거나 자동 수집하여 비교한다 | P2 |

## 5. 기능 요구사항

### Module 1. 견적서 파싱 (Quotation Parser)

| ID | 기능 | 상세 |
|----|------|------|
| F-101 | 파일 업로드 | Excel(.xlsx), PDF 지원. 드래그앤드롭 가능 |
| F-102 | 자동 추출 | 품목명, 규격/사양, 수량, 단가, 공급사명, 견적일자 추출 |
| F-103 | 추출 결과 편집 | 자동 추출 오류 시 사용자가 직접 수정 가능 |
| F-104 | 다중 공급사 비교 | 동일 청구 건에 대해 복수 견적서 동시 업로드 및 비교 |

### Module 2. AI 유사도 분석 (Similarity Engine)

| ID | 기능 | 상세 |
|----|------|------|
| F-201 | 품목 임베딩 | 품목명·규격을 벡터화하여 의미 기반 유사도 계산 |
| F-202 | 유사 품목 검색 | 표준단가 DB에서 유사도 상위 N개 품목 및 점수 반환 |
| F-203 | 매핑 확정 | 사용자가 AI 추천 매핑을 확인·수정·확정 |
| F-204 | 학습 피드백 | 사용자 수정 이력을 모델 개선에 반영 |

### Module 3. 표준단가 DB (Standard Price DB)

| ID | 기능 | 상세 |
|----|------|------|
| F-301 | DB 조회 | 품목코드·품목명·규격·최저/평균/최고 단가·최종 구매일 |
| F-302 | 수동 등록 | 관리자가 품목 및 단가 직접 등록·수정 |
| F-303 | 자동 갱신 | 확정 구매 건 데이터 자동 누적 및 평균 단가 재산출 |
| F-304 | 이력 관리 | 단가 변경 이력 저장 및 조회 |

### Module 4. 비교·분석 대시보드 (Analysis Dashboard)

| ID | 기능 | 상세 |
|----|------|------|
| F-401 | 3-way 비교표 | 견적가 / 표준단가 / 시장가 컬럼 구성, 차이율(%) 표시 |
| F-402 | 이상가 알림 | 표준단가 대비 임계값(예: +15%) 초과 품목 자동 강조 |
| F-403 | 단가 시뮬레이터 | 할인율·조정률 슬라이더 입력 → 조정 단가 실시간 반영 |
| F-404 | 절감 가능 금액 | 표준단가 기준 협상 시 절감 가능 금액 산출 |
| F-405 | 리포트 출력 | 비교 결과 Excel 다운로드 |

### Module 5. 외부 시장가 연계 (Market Price Reference)

| ID | 기능 | 상세 |
|----|------|------|
| F-501 | 수동 입력 | 외부 시장가 직접 입력 후 비교 반영 |
| F-502 | 자동 수집 (2단계) | 나라장터, 인터넷 쇼핑몰 등 오픈 API 또는 크롤링 연계 |

## 6. 비기능 요구사항

| 구분 | 요구사항 |
|------|----------|
| 성능 | 견적서 파싱 및 유사도 분석 결과 반환 30초 이내 |
| 보안 | 견적 데이터는 사내망 내 저장, 외부 전송 금지 |
| 가용성 | 업무 시간 (08:00~18:00) 99% 이상 가용 |
| 확장성 | 품목 DB 10만 건까지 성능 저하 없이 검색 |
| 사용성 | 별도 교육 없이 사용 가능한 직관적 UI |
| 언어 | 한국어 UI 기본, 품목명 한/영 혼용 지원 |

## 7. 시스템 아키텍처 (개요)

```
[사용자 PC]
    ↓ 파일 업로드
[웹 애플리케이션 (Frontend)]
    ↕ REST API
[백엔드 서버]
 ├─ 파싱 엔진 (Python: pdfplumber, openpyxl)
 ├─ AI 유사도 엔진 (Embedding Model + Vector DB)
 └─ 분석 엔진 (단가 비교·시뮬레이터)
    ↕
[데이터베이스]
 ├─ 표준단가 DB (RDB: PostgreSQL)
 └─ 벡터 인덱스 (FAISS / pgvector)
```

## 9. MVP (최소 기능 제품) 정의

MVP는 **P0 기능만** 포함:
- 견적서 Excel 업로드 및 품목 자동 추출
- AI 유사도 분석으로 표준단가 DB 검색
- 견적가 vs 표준단가 비교표 출력 (이상가 하이라이트)

**목표 완료 시점**: 과제 기간 내 MVP 시연 가능 수준

---

## 10. 출시 단계 계획

| 단계 | 내용 | 목표 시점 |
|------|------|-----------|
| Phase 1 (MVP) | 파싱 + AI 유사도 + 비교표 | 과제 종료 시점 |
| Phase 2 | 시뮬레이터 + 리포트 + DB 자동 갱신 | MVP 이후 1개월 |
| Phase 3 | 시장가 자동 수집 + 단가 추이 그래프 | Phase 2 이후 2개월 |
