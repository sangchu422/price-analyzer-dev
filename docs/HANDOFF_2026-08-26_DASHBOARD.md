# Dashboard Command Center 인수인계 — 2026-08-26

## 중요한 데이터 원칙

### 카테고리

카테고리는 시연과 탐색을 위한 넓은 분류다. 모든 표준 품목에 하나의 분류를
부여하지만, 키워드가 없는 품목은 신뢰도 25의 `공통 설비·부품`으로 남긴다.
카테고리는 가격 병합·표준 품목 병합·판정 근거로 사용하지 않는다. 새 분류는
기존 행을 갱신하지 않고 `supersedes_assignment_id`로 연결해 추가한다.

### 설비별 합산

`.xlsx`/`.xlsm`에서 `단위장비N`, `설비N`, `#N` 시트를 찾고 각 시트 `C1`의
설비명을 사용한다. 갑지 또는 표지의 설비명과 H열 금액을 연결하며, 표지에
`천원` 표기가 있으면 원 단위로 환산한다.

갑지 견적 금액을 기준으로 하되 상세 품목에서 산출된 양의 절감액만 차감한다.
따라서 상세 미배부 금액, 공통 전장, 관리비, 이윤을 근거 없이 줄이지 않는다.
구조를 찾지 못한 견적은 `전체 설비`로 묶는 보수적 대체 경로를 사용한다.

### 신규 견적 축적

업로드 직후 문서는 `INCOMING_BID`이며 표준가격 근거가 아니다. 사용자가
담당자와 사유를 입력하고 `표준 DB 반영`을 명시적으로 실행하면 다음 이력을
한 트랜잭션에서 append-only로 추가한다.

1. 문서 역할을 `HISTORICAL_REFERENCE`로 승격
2. 정제 완료 행만 기존 표준 품목에 연결하거나 새 표준 품목 생성
3. 표준가격 새 버전 산출
4. 카테고리 분류 이력 추가
5. 직전 중앙값 대비 ±20% 이상이면 가격 주의 알림 생성
6. 사용자가 선택한 경우에만 Outlook 데스크톱으로 알림 발송 시도

같은 분석 실행을 다시 승인해도 동일한 activation run을 반환해 중복 반영하지
않는다. Outlook 발송 결과도 성공·실패·미지원 상태를 저장한다.

## 대시보드 지표 해석

- 월별 실적: 한 번이라도 신규 견적으로 접수된 고유 문서 수
- 미래 예상: 완료 월의 월평균 접수 건수
- KOSIS 소비자물가: 동기화된 공식 캐시가 있을 때만 공식 자료로 표시
- 원/달러·전기동·냉연강판·제조 임율·반도체 수급: 현재는 시연용 정규화
  인덱스이며 화면에 공식 연동 전이라고 명시

시연용 지표는 구매 판단이나 목표가 계산에 사용하지 않는다.

## 적용 절차

실제 운영 DB 적용 전 DB 파일을 복사해 보관한 뒤 다음 순서로 실행한다.

```bat
set "DATABASE_FILE=%CD%\backend\.local\standard-item-migration-v2.sqlite3"
cd backend
..\.venv\Scripts\python.exe -m alembic upgrade head
cd ..
```

적용 후 확인한다.

1. `alembic current`가 `0016`인지 확인
2. `item_category`가 14개인지 확인
3. 표준 품목 수와 최신 카테고리 배정 수가 같은지 확인
4. `/api/dashboard/overview`가 응답하는지 확인
5. 대시보드의 시연 지표 표기가 보이는지 확인

## 복구

신규 기능 사용 전이라면 Alembic downgrade로 새 테이블만 제거할 수 있다.
하지만 신규 견적을 이미 표준 DB에 승인 반영했다면 기존 이력 테이블에도 새
행이 append되므로 downgrade만으로 논리적 원상복구가 되지 않는다. 이 경우
반드시 적용 전 백업 DB를 복원한다.

```bat
cd backend
..\.venv\Scripts\python.exe -m alembic downgrade 0015
cd ..
```

운영 DB가 아닌 복사본에서 마이그레이션·화면·분류 건수를 먼저 검증한 뒤 실제
DB에 적용한다.
