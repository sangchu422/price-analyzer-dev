# 단계별 실행 로드맵 v2.0
# 협력사 견적 단가 AI 자동 검토 시스템

---

## 전체 3단계 구조

```
Phase 1 (기반 구축)      Phase 2 (자동화)         Phase 3 (고도화·선순환)
────────────────────     ────────────────────     ────────────────────
표준단가 DB 구축          신규 품목 처리           단가 추이 분석
견적서 파싱               할인 룰 엔진             외부 시장가 자동 수집
AI 유사도 엔진 MVP        리포트 출력              DB 자동 갱신 선순환
기본 비교 대시보드         할인 시뮬레이터           복수 협력사 비교
```

---

## Phase 1: 기반 구축 — "비교가 가능한 상태 만들기"
### 기간: 약 4~6주

### 목표
AI 분석의 기반이 되는 표준단가 DB를 구축하고,
견적서에서 품목을 추출하여 기본 비교표를 출력하는 MVP를 완성한다.

---

### Step 1-1. 표준단가 DB 구축 (1~2주)

**내용**
- 과거 견적·발주·계약 단가 데이터 수집 및 정제
- 품목 분류 체계 정의 (물품 / 설비 / 공사 / 용역)
- 표준단가 DB 초기 적재

**산출물**
- 정제된 표준단가 데이터셋 (Excel 또는 CSV)
- 품목 분류 체계표

**판단 기준**: 최소 300건 이상 적재 완료 시 다음 단계 진행

---

### Step 1-2. 견적서 파싱 엔진 개발 (1~2주)

**내용**
- 견적서 샘플 10건 분석 → 컬럼 패턴 파악
- Excel/PDF 자동 파싱 코드 개발
- 추출 결과 수동 수정 기능

**산출물**
- 견적서 파싱 모듈 (Python)
- 샘플 10건 파싱 정확도 검증 결과

---

### Step 1-3. AI 유사도 엔진 개발 (1~2주)

**내용**
- 한국어 임베딩 모델 선정 및 테스트
- 표준단가 DB 품목명 벡터 인덱스 구축
- 입력 품목 → 유사 품목 Top-5 반환 기능

**산출물**
- 유사도 검색 모듈
- 정확도 검증 결과 (샘플 50건 기준 80% 이상 목표)

---

### Step 1-4. MVP 대시보드 개발 (1주)

**내용**
- 견적서 업로드 → 파싱 → 유사도 매핑 → 비교표 출력 흐름 연결
- 이상가(허용 범위 초과) 품목 자동 하이라이트
- 적정 단가 제안 텍스트 자동 생성

**산출물**
- 동작하는 MVP 웹 앱 (Streamlit 기반)
- 내부 테스트 결과 보고서

---

### Phase 1 완료 기준 (Definition of Done)
```
✅ 견적서 Excel 업로드 → 품목·단가 자동 추출 동작
✅ 표준단가 DB 유사 품목 검색 및 차이율 표시
✅ 이상가 자동 강조 + 적정 단가 제안 출력
```

---

### Phase 1에서 제게 필요한 것 (요청사항)

| # | 필요 항목 | 용도 | 우선순위 |
|---|-----------|------|----------|
| 1 | **과거 견적/발주 데이터** (최소 1~2년치, Excel) | 표준단가 DB 초기 적재 | ★★★ |
| 2 | **견적서 샘플 10건** (다양한 양식 포함) | 파싱 엔진 개발 및 테스트 | ★★★ |
| 3 | **품목 분류 기준** (현재 사내에서 사용하는 분류 체계가 있다면) | 표준단가 DB 분류 구조 설계 | ★★ |
| 4 | **이상가 임계값 기준** ("표준단가 대비 몇 % 초과 시 이상으로 볼 것인가") | 자동 판정 룰 설정 | ★★ |

## Phase 2: 자동화 — "신규 품목도, 리포트도 자동으로"
### 기간: Phase 1 완료 후 약 3~4주

### 목표
DB에 없는 신규 품목도 처리하고, 협상 자료로 바로 쓸 수 있는 Excel 리포트를 자동으로 생성한다.

---

### Step 2-1. 할인 룰 엔진 개발

**내용**
- 품목 분류별 사전 정의 할인율 구조 설계
- 신규 품목에 할인 룰 자동 적용 로직 개발
- 할인 시뮬레이터 UI (슬라이더 입력 → 조정 단가 실시간 계산)

---

### Step 2-2. 외부 시장가 조회 연계

**내용**
- 나라장터 오픈 API 연계 (또는 수동 입력 UI 먼저)
- 시장가 vs 견적가 비교 컬럼 추가

---

### Step 2-3. 검토 리포트 자동 생성

**내용**
- 비교 분석 전체 결과 → Excel 리포트 다운로드
- 협상 참고 가격·절감 가능 금액 포함
- 예외(이상가) 항목 별도 시트 자동 추출

---

### Phase 2 완료 기준
```
✅ 신규 품목 할인 룰 + 시장가 기반 적정가 추정 동작
✅ Excel 리포트 자동 생성 (협상 자료로 바로 사용 가능)
✅ 할인 시뮬레이터 UI 동작
```

---

### Phase 2에서 제게 필요한 것 (요청사항)

| # | 필요 항목 | 용도 | 우선순위 |
|---|-----------|------|----------|
| 5 | **품목 분류별 할인율 기준** (예: 물품 10%, 설비 5%, 용역 15%) | 할인 룰 엔진 설계 | ★★★ |
| 6 | **현재 사용 중인 리포트 양식** (Excel 견적 검토 서식이 있다면) | 출력 리포트 포맷 설계 | ★★ |
| 7 | **외부 시장가 참조 방법** (현재 어느 사이트·채널을 주로 참조하는지) | 외부 가격 수집 방향 결정 | ★★ |

## Phase 3: 고도화·선순환 — "쓸수록 똑똑해지는 시스템"
### 기간: Phase 2 완료 후 약 4~6주

### 목표
검토 결과가 자동으로 DB에 누적되어 표준단가가 지속 고도화되고,
단가 추이·복수 협력사 비교 등 고급 분석 기능을 완성한다.

---

### Step 3-1. 표준단가 자동 갱신 워크플로

**내용**
- 검토·승인된 단가 등록 UI
- 신규 데이터 누적 → 평균 단가 자동 재산출
- 단가 변경 이력 저장 및 이력 조회

---

### Step 3-2. 단가 추이 분석 대시보드

**내용**
- 품목별 월별 단가 변동 그래프
- 계절성·물가 연동 추이 시각화

---

### Step 3-3. 복수 협력사 비교

**내용**
- 동일 청구 건에 복수 견적서 동시 업로드
- 사별 품목·단가 비교표 자동 생성
- 최저가·추천 업체 자동 표시

---

### Phase 3 완료 기준
```
✅ 승인 단가 등록 → 표준단가 DB 자동 갱신 동작
✅ 품목별 단가 추이 그래프 조회 가능
✅ 복수 협력사 견적 동시 비교 동작
✅ 선순환 구조 (견적 검토 → DB 누적 → 정확도 향상) 완성
```

---

### Phase 3에서 제게 필요한 것 (요청사항)

| # | 필요 항목 | 용도 | 우선순위 |
|---|-----------|------|----------|
| 8 | **단가 승인 권한 체계** (누가 최종 단가를 확정하는가) | 자동 갱신 워크플로 설계 | ★★ |
| 9 | **ERP 연계 여부 결정** (IT팀 협의 완료 여부) | DB 연동 방향 결정 | ★ |
