# 프로젝트 발표용 시장가 기능 설명

## 한 문장 소개

과거 입찰 견적을 기반으로 구축한 내부 표준 DB를 우선 적용하고, 내부 근거가
없는 품목만 DeviceMart와 Mouser 시장가로 보완하는 근거 추적형 견적 적정성
분석 시스템입니다.

## 발표 시 설명 순서

1. **내부 근거 우선**
   - 회사가 실제로 받은 과거 견적서를 정제해 내부 표준 DB를 구축합니다.
   - 신규 견적은 먼저 내부의 동일 품목·규격·단가 범위와 비교합니다.
2. **시장가 캐시로 보완**
   - 내부 매칭이 없는 품목은 미리 수집한 시장가 DB를 먼저 확인합니다.
   - 전체 사이트를 복제하지 않고 실제 비교 가능성이 높은 품목만 축적합니다.
3. **필요할 때만 실시간 조회**
   - 저장된 가격이 없거나 7일의 유효기간이 지나면 DeviceMart와 Mouser를
     다시 조회합니다.
   - 조회 결과는 다음 분석에서 재사용할 수 있도록 시장가 DB에 저장합니다.
4. **근거를 화면에서 바로 확인**
   - 각 가격 옆에 판매처, 상품 사진, 제조사·모델, 원본 링크와 조회 시각을
     표시합니다.
   - 수집 당시 API 응답, HTML과 페이지 캡처까지 보존해 사후 검증이 가능합니다.

## 강조할 차별점

- 내부 과거 견적과 외부 시장가를 섞지 않고 근거의 성격을 구분합니다.
- 캐시 우선 방식으로 외부 호출량과 분석 시간을 줄입니다.
- 수량 구간, 재고, 최소 주문수량과 가격 조건을 함께 비교합니다.
- 출처·링크·사진·수집 화면이 남아 “왜 이 가격으로 판정했는지” 설명할 수
  있습니다.
- 외부 조회 실패 시 임의 가격을 생성하지 않고 담당자 검토 대상으로 남깁니다.

## 화면 시연 시나리오

1. 신규 견적 파일을 `/analysis`에 첨부합니다.
2. 내부 표준 DB에 있는 품목은 과거 견적 가격 범위로 판정되는 것을 보여줍니다.
3. 내부 미매칭 품목은 시장가 DB 또는 실시간 조회 결과로 보완되는 것을
   보여줍니다.
4. 출처 배지와 상품 사진을 선택해 원본 상품 페이지와 수집 증빙을 확인합니다.
5. 품목별 판정과 견적서 전체 요약으로 돌아와 최종 검토 흐름을 설명합니다.
