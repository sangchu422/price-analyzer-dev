# 시장가 캐시·실시간 보완·증빙 설계

작성일: 2026-07-27
상태: 사용자 승인 완료

## 1. 목적

신규 견적 품목이 내부 표준 DB와 신뢰 가능하게 매칭되지 않을 때
DeviceMart와 Mouser Korea의 판매가격을 보조 근거로 제공한다. 외부 가격은
내부 표준단가와 분리하고, 사용자가 가격의 출처와 수집 당시 원본을 직접
확인할 수 있게 한다.

## 2. 수집 범위

- 전체 사이트 카탈로그는 복제하지 않는다.
- 회사에서 비교 가능성이 높은 품목과 검토된 검색 목록은 일괄 사전 수집한다.
- 신규 견적 분석 중 내부 표준 DB에 매칭되지 않은 품목은 실시간 조회한다.
- 실시간 조회 결과는 시장가 DB에 저장해 같은 품목의 다음 조회에 재사용한다.
- 유효한 캐시가 있으면 외부 사이트를 호출하지 않는다.
- 기본 유효기간은 7일이며 만료된 가격은 최신 가격으로 판정하지 않는다.

## 3. 출처별 방식

### Mouser Korea

- 공식 Search API를 사용한다.
- 제조사 부품번호를 우선하고 품명·규격 키워드를 보조 검색어로 사용한다.
- 모든 가격 구간, 통화, 재고, 최소 주문수량과 상품·이미지 URL을 저장한다.
- 원본 JSON 응답을 수집 증빙으로 보존한다.

### DeviceMart

- 공개 검색 결과와 상품 상세페이지를 수집한다.
- 품명, 모델, 제조사, 판매가, 재고, 상품 URL과 이미지 URL을 저장한다.
- 수집 당시 HTML과 전체 페이지 캡처 이미지를 증빙으로 보존한다.
- 페이지 구조가 바뀌면 해당 수집만 실패 처리하고 기존 캐시는 유지한다.

## 4. 데이터와 증빙

시장가 데이터는 다음 네 구조로 분리한다.

- `market_product`: 출처 상품 ID, 제조사 부품번호, 품명·규격·제조사,
  상품 URL과 이미지 URL
- `market_price_snapshot`: 수량 구간별 가격, 통화, 재고, 최소 주문수량,
  부가세·배송비 조건, 수집·만료 시각
- `market_evidence`: API JSON, HTML, 상품 이미지, 페이지 캡처, 원본 URL,
  SHA-256과 수집기 버전
- `market_lookup_run`: 검색어, 캐시 적중 여부, 호출한 출처, 성공·실패와
  사용한 가격 스냅숏

상품 사진은 원격 URL과 수집 당시 로컬 사본을 함께 저장한다. 외부 페이지나
이미지가 변경돼도 당시 판정 근거를 확인할 수 있어야 한다.

## 5. 조회와 판정 흐름

1. 신규 견적 품목을 내부 표준 DB와 매칭한다.
2. 내부 가격 근거가 있으면 내부 표준단가를 주 근거로 사용한다.
3. 내부 매칭이 없으면 유효한 시장가 캐시를 검색한다.
4. 캐시가 없거나 만료됐으면 DeviceMart와 Mouser를 조회한다.
5. 외부 결과와 증빙을 저장하고 견적 수량에 맞는 가격 구간을 선택한다.
6. 통화·부가세·배송비·최소 주문 조건이 비교 가능한 결과만 시장가 범위에
   포함한다.
7. 외부 조회가 모두 실패하면 근거 없는 가격을 만들지 않고 검토 대기로 둔다.

## 6. 웹 표시

신규 견적 분석 행에는 다음 정보를 나란히 표시한다.

| 견적 정보 | 비교 결과 | 시장가 출처와 증빙 |
|---|---|---|
| 품명·규격·수량·제시 단가 | 시장가 최저·중앙·최고, 차이율, 저가·적정·고가·검토 | 출처 배지, 상품 사진, 제조사·모델, 재고·MOQ, 수집 시각 |

각 결과에는 `원본 상품 보기`와 `수집 증빙 보기`를 제공한다. 증빙 화면에서는
원본 링크, 로컬 사진, API 응답 또는 HTML과 페이지 캡처를 확인한다.

## 7. 오류 처리

- 한 출처가 실패해도 다른 출처와 내부 표준 DB 분석은 계속한다.
- 만료 가격은 `기간 만료`로 표시하고 최신 판정에는 사용하지 않는다.
- 상품 사진 저장 실패는 가격 저장을 막지 않으며 원격 URL과 경고를 남긴다.
- 파싱할 수 없는 가격이나 통화는 추정하지 않고 제외 사유를 기록한다.
- DeviceMart 화면 구조 변경은 수집기 오류로 기록하고 기존 증빙을 보존한다.

## 8. 검증 조건

- 캐시 적중 시 외부 호출이 발생하지 않는다.
- 미보유·만료 품목만 실시간 조회한다.
- 수량에 맞는 가격 구간이 선택된다.
- 내부 표준단가와 외부 시장가가 혼합 저장되지 않는다.
- 모든 사용 가격에서 출처 URL, 수집 시각과 원본 증빙을 역추적할 수 있다.
- 외부 연결 없는 테스트에서는 모의 API 응답과 HTML로 전체 흐름을 검증한다.
- 실제 연동은 명시적인 로컬 명령에서만 실행하며 서버 스케줄러는 포함하지
  않는다.

## 9. 발표용 핵심 문장

“과거 입찰 견적을 기반으로 만든 내부 표준 DB를 우선 사용하고, 내부 근거가
없는 품목만 외부 시장가 캐시와 실시간 조회로 보완합니다. 모든 외부 가격에는
판매처, 원본 링크, 상품 사진, 조회 시각과 수집 당시 화면을 함께 보존해
가격 판정의 근거를 다시 확인할 수 있습니다.”
