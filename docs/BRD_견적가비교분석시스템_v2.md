## 2. 과제 한 줄 정의

> "과거 견적·발주 이력, 할인 룰, 외부 시장가를 결합해 협력사 견적의 적정성을 AI로 자동 분석하고, 그 결과를 다시 표준단가 DB에 축적해 지속적으로 고도화하는 시스템 구축 과제"

---

## 3. 현황 및 문제 정의 (As-Is)

### 3.1 현재 업무 방식
- 담당자가 **과거 유사 발주 데이터를 수작업으로 검색·비교**하여 견적 적정성 판단
- 견적서 형식이 협력사마다 달라 데이터 정리에 별도 시간 소요
- 검토 기준이 담당자 경험에 의존하여 **일관성 부재**

### 3.2 핵심 문제

| # | 문제 | 영향 |
|---|------|------|
| P1 | 유사 품목 매칭이 수작업 → 시간 과다 소요 | 업체 선정 지연 |
| P2 | 참조 이력에 따라 추출 단가가 다름 → 비일관성 | 가격 판단 신뢰도 저하 |
| P3 | 검토자 경험에 따라 판단 편차 발생 | 구매 기준 표준화 불가 |
| P4 | 외부 시세·할인 조건을 체계적으로 반영 불가 | 협상 근거 부족 |
| P5 | 검토 결과가 데이터로 축적되지 않음 | 조직 학습 불가 |

## 4. 비즈니스 목표

| # | 목표 | 측정 지표 |
|---|------|-----------|
| B1 | 견적 검토 시간 단축 | 건당 검토 시간 50% 이상 감소 |
| B2 | 검토 기준 표준화 | 담당자별 단가 판단 편차 제거 |
| B3 | 과다 견적 사전 차단 | 허용 범위 초과 견적 자동 탐지율 90% 이상 |
| B4 | 협상력 강화 | 모든 견적 건에 협상 근거 자료 자동 제공 |
| B5 | 표준단가 DB 지속 고도화 | 분기별 신규 품목 자동 누적 체계 구축 |

## 5. 과제 핵심 4대 목표

```
① 표준단가 DB 구축
        ↓
② 협력사 견적서 자동 분석
        ↓
③ 견적가 검토 및 최적 가격 제안
        ↓
④ 표준단가 지속 업데이트 (선순환)
        ↑_________________________|
```

이 4단계는 **선순환 구조**로 설계됩니다.
검토 결과가 DB에 다시 쌓이면서 시스템 정확도가 지속적으로 향상됩니다.

## 6. 비즈니스 요구사항

### BR-01. 표준단가 DB 구축
- 기존 견적·발주·계약 단가 이력 데이터 수집 및 정제
- 품목 유형별 분류 체계 구축: **물품 / 설비 / 공사 / 용역**
- 견적서 양식 표준화 (협력사별 상이한 형식 통일)

### BR-02. 협력사 견적서 자동 분석
- 표준단가 DB 내 동일/유사 품목 자동 검색 (AI 유사도 기반)
- 사전 정의된 룰에 따라 할인 조건 자동 반영
- 표준단가 DB에 없는 품목은 외부 시장가 자동 조회 (RPA 또는 Open API)

### BR-03. 견적가 검토 및 최적 가격 제안

**[경우 1] 표준단가 DB 존재 품목**
- 표준단가와 차이율 분석
- 허용 범위(임계값) 초과 여부 자동 판정
- 견적가 또는 표준단가 적용 의사결정 지원

**[경우 2] 표준단가 DB 미존재 품목 (신규)**
- 사전 정의 할인율 적용
- 외부 시장가격 비교
- 유사 품목 추론을 통한 가격 추정

**공통 산출물**
- 적정 단가 제안 / 검토 의견 자동 생성 / 협상 참고 가격 제시 / 예외 항목 식별

### BR-04. 표준단가 지속 업데이트
- 실제 검토·승인된 견적 데이터 자동 누적
- 계약 단가 이력 반영 및 표준단가 재산출
- 표준단가 추천 로직 지속 개선

## 7. 품목 분류 체계

| 분류 | 설명 | 예시 |
|------|------|------|
| 물품 | 규격화된 소모품·자재 | 볼트, 윤활유, 포장재 |
| 설비 | 기계·장치류 | 컨베이어, 공작기계 |
| 공사 | 시설·건설 공사 | 배관공사, 도장공사 |

## 9. 기대 효과

### 정량 효과
- 견적 검토 시간 단축 (목표: 50% 이상)
- 수작업 비교 분석 감소
- 과다 견적 사전 차단
- 표준단가 활용률 증가

### 정성 효과
- 담당자 경험 의존도 감소
- 검토 기준 표준화
- 협력사 대응 논리 강화
- 가격 협상력 향상
- 구매 의사결정의 객관성 확보

---

## 10. 범위

### 포함 (In-Scope)
- 표준단가 DB 구축 및 관리
- 견적서 자동 파싱 (Excel, PDF)
- AI 유사도 기반 품목 매핑
- 할인 룰 기반 적정가 산출
- 외부 시장가 조회 연계
- 검토 결과 리포트 및 DB 자동 갱신

### 제외 (Out-of-Scope, 초기)
- ERP 자동 발주 연동
- 협력사 포털 직접 연동
- 해외 구매·외화 환산 (추후 확장)
