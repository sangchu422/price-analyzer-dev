# `.env` Git 이력 점검

점검일: 2026-07-27

## 결과

- 현재 추적 파일에는 실제 `.env`가 없고 `.env.example`만 존재한다.
- `.gitignore`는 루트와 하위 디렉터리의 `.env`를 모두 차단한다.
- 전체 로컬 브랜치·태그 이력을 검사한 결과, 과거
  `price_analyzer_v2/.env`가 Git에 추가된 뒤 삭제된 이력이 확인됐다.
  - 추가 커밋: `36fbf436543a67d6e942732a673e2c98c04f3f0f`
  - 삭제 커밋: `a45ffe5a61f87c6741c9dd31c90f0f624ddeb67d`
- 과거 파일에는 빈 값이나 예시값으로 판별되지 않는 `H_CHAT_API_KEY`가
  존재했다. 비밀값 자체는 문서와 점검 출력에 기록하지 않았다.

## 필요한 조치

1. 과거 `H_CHAT_API_KEY`는 노출된 값으로 간주해 사내 환경에서 폐기하고
   새 키를 발급한다. 기존 키를 현재 설정에 재사용하지 않는다.
2. 새 키는 로컬 `.env` 또는 사내 비밀관리 수단에만 저장하고 Git에
   커밋하지 않는다.
3. 이 저장소는 개인 비공개 저장소이지만, 키 교체 후 필요하면 별도 승인된
   작업으로 Git 이력을 정리한다. 이력 재작성과 강제 푸시는 협업자 로컬
   브랜치에 영향을 주므로 이번 수정에는 포함하지 않는다.

## 재점검 명령

저장소 루트의 `cmd.exe`에서 실행한다.

```bat
git log --all --full-history --name-status -- ".env" "**/.env"
git ls-files | findstr /R /C:"^\.env$" /C:"/\.env$"
```

이 명령으로 파일 경로와 커밋 이력만 확인한다. `git show`로 과거 비밀값을
화면에 출력하지 않는다.
