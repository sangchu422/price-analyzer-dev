## 2026-07-24 — 표준단가 DB의 출처와 보안 파일 처리

### 표준단가 DB 정의

- `표준단가DB`는 회사가 협력사 등으로부터 실제로 받은 **과거 견적서**를 정제·집계해 구축한 내부 견적 이력 DB다.
- 따라서 표준단가는 외부 시장가격이나 공개 사이트의 판매가격을 의미하지 않는다.
- 외부 API·가격 비교 사이트·크롤링으로 수집한 가격은 `외부 시장가`로 별도 저장한다.
- 가격 검토 시 내부 DB에서 동일·유사 품목이 검색되면 과거 견적 단가를 우선 비교 근거로 사용한다.
- 내부 DB에 신뢰할 만한 매칭이 없을 때만 외부 시장가를 보조 근거로 조회한다.

## 2026-07-24 — 표준단가 지정 정책 및 임베딩 API

### 표준단가 지정 정책

- 근거 견적 건수와 무관하게 **모든 집계 품목을 표준단가로 지정**한다.
- DB 데이터 절대량이 적으므로 1건짜리 집계도 표준단가로 취급한다.
- `후보단가` 분리 없음 — `status` 필드 추가 불필요.
- 향후 데이터 축적 후 재검토 가능.

### 임베딩 API

- 외부 `sentence-transformers + FAISS` 구성 **취소**.
- 사내 **hChat API (OpenAI 호환)** 사용 확정.
- 클라이언트: `AzureOpenAI`, 모델: `text-embedding-3-small` (1536차원, 256 축소 가능).
- 환경변수: `H_CHAT_API_KEY`, `H_CHAT_BASE_URL`, `H_CHAT_PROJECT_ID`.
- API Key는 사용자가 별도 제공 예정.
