# Procurement Intelligence Command Center

## 화면의 역할

첫 화면은 장식용 랜딩 페이지가 아니라 구매 담당자가 오늘 처리할 일을 한 번에
판단하는 지휘 화면이다. 왼쪽에는 표준 DB의 규모·가격 근거 상태·카테고리와
정제 대기 작업을, 오른쪽에는 월별 접수 실적·예상 건수·가격 영향 지표·가격
변동 알림을 배치한다.

화면의 시각적 위계는 다음 질문 순서를 따른다.

1. 지금 표준 DB로 얼마나 판단할 수 있는가?
2. 아직 사람이 확인해야 할 일은 몇 건인가?
3. 올해 견적 접수 실적과 이후 예상은 어떤가?
4. 원자재·환율·임율·시황이 어느 방향으로 움직이는가?
5. 새로 반영한 가격 가운데 즉시 확인할 이상징후가 있는가?

## 디자인 원칙

- 메인 브랜드 색상은 정확히 `#FF0000`을 사용한다.
- 기본 화면은 발표·업무에 모두 적합한 화이트 모드다.
- 큰 숫자와 핵심 상태에는 강한 대비를 주되, 운영 테이블은 차분하게 유지한다.
- 둥근 카드의 반복보다 비대칭 그리드, 얇은 경계, 넉넉한 여백으로 정보 밀도를
  조절한다.
- 카테고리는 탐색용 분류다. 같은 카테고리라는 이유만으로 품목·가격 근거를
  합치지 않는다.
- 신뢰도가 낮은 자동 분류는 `추정 분류`라고 표시한다.
- 공식 연동 전 원자재·환율·임율·시황 값은 반드시
  `시연 인덱스 · 공식 데이터 연동 전`으로 표시한다.

## 모션 원칙

- 첫 하드 리로드에서만 HYUNDAI WIA 로고 입자가 모여든 뒤 좌측 하단으로
  이동한다. 내부 화면 이동으로 대시보드에 돌아올 때는 반복하지 않는다.
- 차트와 지표는 순차적으로 등장하고 현재 지표가 자동 전환된다.
- 마우스 반응은 방향성을 보여 주는 정도로만 사용하며, 표와 입력 영역에는
  과도한 움직임을 넣지 않는다.
- `prefers-reduced-motion: reduce` 환경에서는 3D 장면과 반복 애니메이션을
  생략한다. WebGL을 사용할 수 없는 환경도 정적 로고로 대체한다.

## 주요 화면 계약

### 종합현황

- 표준 품목 전체, 카테고리 분류, 활성 가격, 가격 근거 없음, 미매칭 정제 완료,
  정제 검토 대기를 서로 다른 상태로 표시한다.
- 월별 실적은 신규 견적으로 접수된 문서를 기준으로 하며, 표준 DB에 승인
  반영된 뒤에도 과거 접수 실적에서 사라지지 않는다.
- 현재 시점 이후 월은 완료 월 평균을 이용한 예상치이며 실적과 시각적으로
  구분한다.

### 표준 DB

- 카테고리 레일로 빠르게 좁혀 보고, 선택한 표준 품목의 연도별 최저·중앙·최고
  가격 추이를 확인한다.
- 견적일이 확인된 독립 원본만 추이에 사용하고 날짜 미확인 건은 별도로 센다.
- 화면 하단에는 정제 검토 대기를 `미분류 TO-DO`로 노출한다.

### 신규 견적 분석

- 갑지의 설비명을 기준으로 견적 금액과 목표 금액, 네고 가능금액을 합산한다.
- 상세를 열면 해당 설비의 원문 품목을 확인할 수 있다.
- 공통 전장·관리비·이윤 등 상세 품목으로 배부하지 못한 금액은 임의로
  절감하지 않고 그대로 유지한다.
- 신규 견적은 기본적으로 표준 DB와 격리한다. 담당자와 반영 사유를 입력해
  명시적으로 승인했을 때만 append-only 이력으로 축적한다.
