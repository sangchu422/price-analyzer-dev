# 프런트엔드 라이브러리 및 참고 출처

## 제품에 포함된 런타임 라이브러리

| 라이브러리 | 버전 | 용도 | 라이선스 | 공식 출처 |
|---|---:|---|---|---|
| Three.js | 0.180.0 | 로고 파티클 WebGL 장면 | MIT | https://threejs.org/ |
| React Three Fiber | 9.7.0 | Three.js 장면의 React 통합 | MIT | https://github.com/pmndrs/react-three-fiber |
| Recharts | 3.10.1 | 월별 실적·시장 지표·가격 추이 차트 | MIT | https://github.com/recharts/recharts |

버전과 라이선스 값은 설치된 각 패키지의 `package.json`을 기준으로 기록했다.
