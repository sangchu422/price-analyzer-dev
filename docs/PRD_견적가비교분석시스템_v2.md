## 2. 제품 비전

> "견적서를 올리면 AI가 표준단가·할인 룰·외부 시장가를 종합해 적정 가격을 자동 제안하고,
> 검토할수록 DB가 똑똑해지는 구매 인텔리전스 시스템"

---

## 3. 전체 시스템 흐름

```
[Input]
  협력사 견적서 (Excel / PDF)
        ↓
[Step 1] 견적서 파싱
  · 품목명·규격·수량·단가 자동 추출
  · 표준 양식으로 변환
        ↓
[Step 2] 품목 분류 및 AI 유사도 분석
  · 물품 / 설비 / 공사 / 용역 분류
  · 표준단가 DB 유사 품목 검색
        ↓
     ┌────────────────┬───────────────────┐
     ▼                                   ▼
[DB 존재 품목]                    [DB 미존재 품목 (신규)]
 · 표준단가 vs 견적가 비교          · 할인 룰 자동 적용
 · 차이율 계산                      · 외부 시장가 조회
 · 허용 범위 초과 여부 판정         · 유사 품목 추론
     └────────────────┬───────────────────┘
                      ▼
[Step 3] 검토 리포트 생성
  · 적정 단가 제안
  · 검토 의견 자동 생성
  · 협상 참고 가격
  · 예외(이상가) 항목 식별
        ↓
[Step 4] 결과 DB 반영 (선순환)
  · 승인 단가·계약 단가 누적
  · 표준단가 자동 갱신
  · 추천 로직 개선 피드백
```

## 4. 핵심 사용자 스토리

| ID | 사용자 | 스토리 | 우선순위 |
|----|--------|--------|----------|
| US-01 | 책임매니저 | 견적서(Excel/PDF)를 업로드하면 품목·수량·단가가 자동으로 추출된다 | **P0** |
| US-02 | 책임매니저 | 추출된 품목이 물품/설비/공사/용역 중 어디에 해당하는지 자동 분류된다 | **P0** |
| US-03 | 책임매니저 | 표준단가 DB 내 유사 품목과 매핑 결과 및 유사도 점수를 확인한다 | **P0** |
| US-04 | 책임매니저 | DB 존재 품목은 표준단가 대비 차이율과 허용 범위 초과 여부를 자동으로 확인한다 | **P0** |
| US-05 | 책임매니저 | DB 미존재 신규 품목은 할인 룰 + 외부 시장가 기반으로 적정가 추정 결과를 받는다 | **P1** |
| US-06 | 책임매니저 | 모든 품목에 대해 적정 단가 제안·검토 의견·협상 참고가가 담긴 리포트를 Excel로 받는다 | **P1** |
| US-07 | 구매 사원 | 검토·승인된 단가를 등록하면 표준단가 DB에 자동 누적된다 | **P1** |
| US-08 | 책임매니저 | 품목별 단가 이력 추이(월별)를 그래프로 조회한다 | **P2** |
| US-09 | 책임매니저 | 복수 협력사 견적서를 동시에 올려 사 간 가격을 비교한다 | **P2** |

## 5. 기능 요구사항 (4대 모듈)

### Module 1. 표준단가 DB (Standard Price Database)

| ID | 기능 | 상세 |
|----|------|------|
| F-101 | 초기 데이터 적재 | 과거 견적·발주·계약 단가 데이터 일괄 Import (Excel 업로드) |

## 6. 비기능 요구사항

| 구분 | 요구사항 |
|------|----------|
| 성능 | 견적서 파싱~분석 결과 반환 30초 이내 |
| 보안 | 견적 데이터 사내망 내 저장, 외부 전송 금지 |
| 가용성 | 업무 시간(08:00~18:00) 99% 이상 |
| 확장성 | 표준단가 DB 10만 건까지 검색 성능 유지 |
| 사용성 | 별도 교육 없이 사용 가능한 한국어 UI |

## 7. 기술 스택 (권장)

| 구분 | 도구 | 이유 |
|------|------|------|
| 견적서 파싱 | Python (openpyxl, pdfplumber) | Excel/PDF 모두 처리 가능 |
| AI 유사도 엔진 | sentence-transformers (한국어 모델) + FAISS | 온프레미스 운영 가능, 빠른 벡터 검색 |
| 할인 룰 엔진 | Python 룰 기반 로직 | 단순·명확한 룰 정의 용이 |
| 외부 시장가 | Open API (나라장터 등) 또는 RPA | 자동 수집 |
| 백엔드 | FastAPI (Python) | 빠른 개발, AI 라이브러리 연동 최적 |
| 프론트엔드 | Streamlit (MVP) → React (정식) | MVP는 빠르게, 정식은 UX 고도화 |
| DB | PostgreSQL + pgvector | 관계형 + 벡터 검색 통합 |

## 8. MVP 정의 (Phase 1 완료 기준)

MVP는 다음 3가지가 동작하면 성공:

```
① 견적서 Excel 업로드 → 품목·단가 자동 추출
② 표준단가 DB에서 유사 품목 AI 검색 → 차이율 표시
③ 이상가 품목 자동 강조 + 적정 단가 제안 출력
```
