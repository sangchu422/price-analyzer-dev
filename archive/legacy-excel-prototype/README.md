# 레거시 Excel 프로토타입 보관소

이 디렉터리는 현재 제품 이전에 사용했던 Streamlit, Excel, JSON 기반 실험물을
감사와 참고 목적으로만 보존한다.

- 이 코드를 실행하거나 현재 제품의 의존성으로 사용하지 않는다.
- 이 디렉터리의 Excel과 JSON은 운영 표준 DB의 입력, 검증, 비교, 내보내기
  자료가 아니다.
- 특히 `표준단가DB.xlsx`는 초창기 수작업 산출물일 뿐이다.
- 현재 제품은 저장소 루트의 `README.md`, `backend/`, `frontend/`,
  `scripts/start-local.ps1`만 기준으로 실행한다.
- 로컬 `.env`는 Git에 추적하지 않는다. 비밀값을 이 디렉터리에서 복원하거나
  재사용하지 않는다.
