# 견적서 파싱 규칙

`parse_all.py` → `apply_rules.py` 순서로 자동 적용됨.  
새 규칙 추가 시: 아래 문서에 정의 → `apply_rules.py`에 구현 → 파이프라인 재실행.

---

## 규칙 목록

### RULE-01: 단위 키워드 정규화

| 항목 | 내용 |
|------|------|
| 대상 키워드 | `식`, `EA`, `SET`, `M`, `LOT`, `AY`, `MD`/`M/D` (→ `M/D`로 통일) |
| 조건 | 규격·품명·메이커·단위장비명 컬럼에 위 키워드가 단독(정확히 일치)으로 들어있는 경우 |
| 처리 | 해당 값을 "단위" 컬럼으로 이동 |
| 충돌 | 단위에 이미 다른 값이 있으면 서로 위치를 교환(swap) |

---

### RULE-02: 주요메이커 정규화

| 항목 | 내용 |
|------|------|
| 대상 메이커 | `Robostar`, `THK외`, `OMRON`, `APEX`, `THK`, `Unicon`, `Keyence`, `Advantech`, `misumi`, `FESTO`, `닛다모아`, `SMC` |
| 조건 | 규격·품명·단위장비명·단위 컬럼에 위 메이커명이 단독(대소문자 무관)으로 들어있는 경우 |
| 처리 | 해당 값을 "메이커" 컬럼으로 이동, 정규화된 표기로 통일 |
| 충돌 | 메이커에 이미 다른 값이 있으면 서로 위치를 교환(swap) |

---

### RULE-03: 규격 키워드 — 단위 컬럼 오배치 정정

| 항목 | 내용 |
|------|------|
| 조건 | 단위 컬럼에 규격 키워드(케이블 사양 등)가 들어있는 경우 |
| 처리 | 단위→규격으로 이동, 기존 규격값 삭제 |
| 대상 키워드 | `19Ø(녹색)`, `12Ø(흑색)`, `16x12(녹색)`, `12*8(적색)`, `12*8(흑색)`, `1G25(노랑)`, `1G25(녹)`, `1X2X0.64`, `1X2X0.8`, `4G 0.75`, `4G 1`, `25G 0.75`, `15G 0.75`, `12G 0.75`, `4G 2.5`, `7G 1`, `3G 25`, `1C*25SQ(G)`, `1C*25SQ(BK)`, `25G*0.75SQ`, `7G*1.0SQ` |

---

### RULE-04: 품명 유효성 정정

| 항목 | 내용 |
|------|------|
| 대상 품명 | `기계` |
| 처리 순서 | ① 규격 → 품명으로 이동, 규격 비우기<br>② 규격이 비었고 메이커에 비메이커 값이 있으면 → 규격으로 이동 |
| 실행 순서 | RULE-08/09/10 이후 실행 |

---

### RULE-05: 수동 보정

파싱 오류로 컬럼이 완전히 뒤바뀐 특정 항목 또는 특정 품명의 단위를 직접 지정.

| match 조건 | 수정 결과 |
|---|---|
| 품명=`MBC ASS'Y`, 메이커=`OIL JET VISION UNIT` | 품명=`OIL JET VISION UNIT`, 규격=`MBC ASS'Y`, 메이커=빈값 |
| 메이커=`BED EQUIPMENT` | 규격=`BED EQUIPMENT`, 메이커=빈값 |
| 품명=`서버 전송 프로그램` | 단위=`식` |

---

### RULE-06: 품명 = 규격 중복 제거

| 항목 | 내용 |
|------|------|
| 조건 | 품명과 규격이 정확히 동일한 값인 경우 |
| 처리 A | 단위가 모델번호(단위 키워드가 아닌 값)이면 → 단위→규격, 단위=`EA` |
| 처리 B | 단위가 정상 단위 키워드이거나 비어있으면 → 규격만 비우기 |

**예시**

| 품명 | 규격 | 단위 (변경전) | → 규격 | 단위 (변경후) |
|------|------|------|------|------|
| STOPPER | STOPPER | RS2H63-30BMD | RS2H63-30BMD | EA |
| MOTOR | MOTOR | EA | (비움) | EA |

---

### RULE-07: 단위 공백 시 단가 기준 자동 추론

| 항목 | 내용 |
|------|------|
| 조건 | 단위 컬럼이 비어있는 경우 |
| 처리 | 단가_원 기준으로 단위를 자동 추론해 채움 |
| 실행 순서 | 모든 규칙 중 마지막 실행 (컬럼 재배치 후 빈 단위 채우기) |

**단가 → 단위 매핑**

| 단가 범위 | 추론 단위 |
|-----------|-----------|
| 100만원 미만 | `EA` |
| 100만원 이상 ~ 1,000만원 미만 | `SET` |
| 1,000만원 이상 | `식` |

---

### RULE-08: 카테고리 레이블 품명 → 3단 컬럼 시프트 + 단위=EA

| 항목 | 내용 |
|------|------|
| 조건 | 품명이 카테고리 레이블인 경우 |
| 대상 레이블 | `구매품`, `(유공압품외)`, `DIVERTER`, `TURNING POSITION`, `(OP...)` 패턴 |
| 처리 | 규격→품명, 단위→규격, 단위=`EA` |
| 조건 보조 | 규격이 비어있으면 시프트 불가 → 스킵 |

**예시**

| 품명 (변경전) | 규격 | 단위 | → 품명 (변경후) | 규격 | 단위 |
|---|---|---|---|---|---|
| `(유공압품외)` | 작업지시 MONITOR | 24",거치대,USB | 작업지시 MONITOR | 24",거치대,USB | EA |
| `구매품` | 스마트 비전 | IV3-G500CA | 스마트 비전 | IV3-G500CA | EA |

---

### RULE-09: 자재비+철자재 패턴 → 단위가 실제 품명

| 항목 | 내용 |
|------|------|
| 조건 | 품명=`자재비` AND 규격=`철자재` AND 단위가 단위 키워드가 아닌 값(실제 품명) |
| 처리 | 단위→품명, 규격=`철자재` 유지, 단위=비우기 |
| 단위 채우기 | 이후 RULE-07이 단가 기준으로 자동 채움 |

**예시**

| 품명 (변경전) | 규격 | 단위 | → 품명 (변경후) | 단위 (RULE-07 후) |
|---|---|---|---|---|
| `자재비` | 철자재 | Main Frame Unit | Main Frame Unit | SET (단가 360만) |
| `자재비` | 철자재 | 겐트리 로더 | 겐트리 로더 | 식 (단가 1억) |

---

### RULE-10: (NSET) 형태 품명 → 컬럼 시프트 + 단위=SET

| 항목 | 내용 |
|------|------|
| 조건 | 품명이 `(숫자SET)` 형태 (예: `(30SET)`, `(2SET)`) |
| 처리 | 규격→품명, 단위→규격, 단위=`SET` |
| 조건 보조 | 규격이 비어있으면 시프트 불가 → 스킵 |

**예시**

| 품명 (변경전) | 규격 | 단위 | → 품명 (변경후) | 규격 | 단위 |
|---|---|---|---|---|---|
| `(30SET)` | SOL VALVE | VQC2000 SERIES | SOL VALVE | VQC2000 SERIES | SET |

## 실행 순서

```
RULE-01 → RULE-02 → RULE-03    # 단위/메이커/규격 키워드 위치 정정
→ RULE-08 → RULE-09 → RULE-10  # 카테고리/자재비/NSET 패턴 컬럼 재배치
→ RULE-04 → RULE-05 → RULE-06  # 품명 정정, 수동 보정, 중복 제거
→ RULE-07                       # 빈 단위 채우기 (마지막)
```

---

## 향후 정리 방향

- 현재 규칙들은 특정 케이스에서 귀납적으로 도출된 구체적 규칙임
- 데이터가 쌓이면 보편화 검토 필요:
  - 카테고리 레이블 목록 확장
  - 규격 키워드 목록 확장
  - NSET 외 수량 표현 패턴 통합
